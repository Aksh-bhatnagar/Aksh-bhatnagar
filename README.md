## Featured Projects

### 1. Golden Minutes

**Multilingual voice assistant for cyber-fraud reporting**

A conversational voice assistant designed to help people collect and organize cyber-fraud incident details in English, Hindi, and Hinglish.

- Integrates speech-to-text and text-to-speech with an LLM-powered conversation flow.
- Collects structured incident details and generates PDF reports.
- Implements interruption handling for a more natural voice interaction.
- Achieved **96.7% field accuracy (58/60)** across six synthetic test scenarios.

**Tech:** Python, FastAPI, Groq, Gnani STT/TTS, LLMs, asynchronous processing

[Source Code](https://github.com/Aksh-bhatnagar)

### 2. SpeechTrust

**Speech analysis and response evaluation system**

An application that analyzes spoken responses using audio features and semantic relevance scoring.

- Combines speech processing with semantic similarity to evaluate responses.
- Uses Whisper, Librosa, and Sentence Transformers.
- Provides confidence-oriented scoring through a full-stack application.
- Includes authentication and a structured question bank.

**Tech:** Python, FastAPI, Whisper, Librosa, Sentence Transformers, React, Node.js, MongoDB

[Live Demo](https://speechtrust01-p64h.vercel.app/) · [GitHub Repositories](https://github.com/Aksh-bhatnagar?tab=repositories)

### 3. VestIQ

**AI-powered fashion styling and product discovery**

A fashion recommendation application combining visual similarity and product discovery to help users explore relevant clothing options.

- Uses FashionCLIP-based visual representations.
- Integrates a machine learning model into a web application.
- Reports a model ROC-AUC of **0.803**, with a five-fold result of **0.807**.

**Tech:** Python, FastAPI, FashionCLIP, Next.js, Supabase, SerpApi
